:cyclone: SpiralTower 생성 규칙 (최종 최적화본)

:pushpin: 기본 설정
- id: "1014"
- size: (1,1,1) → 각 블록은 좌표 공간에서 100 x 100 x 100을 차지함
- 모든 좌표는 100의 배수여야 함
- 블록 간 충돌이 발생해서는 안 됨 (중복 좌표 불허)

:construction_site: 구조 정의

1. 중앙 원기둥
- 시작 중심점: (5000, 500, 100)
- 내부 반지름: 1400 (14칸), 외부 반지름: 1500 (15칸)
- 외부 반지름과 내부 반지름 사이의 고리 형태로 블록 배치
- 내부 반지름(1400) 안쪽은 완전히 비워야 하며, 어떠한 블록도 배치되어서는 안 됨
- 블록은 반지름 길이에 맞춰 원형 형태로 정확하게 배치

2. 외부 경로 (계단식 나선형 길)
- 원기둥 외곽으로부터 정확히 1000 거리(10칸) 떨어진 위치에 배치 (즉, 반지름 2500 위치)
- 중앙 원기둥의 외곽 블록과 빈틈 없이 직접 연결되어야 함 (접촉)
- 총 3바퀴 나선형으로 원기둥을 감싸며 상승하는 구조
- 각 바퀴마다 다음 패턴을 12회 반복:
  · 평지 15칸 → Z축 +500 상승 → 평지 15칸 → Z축 +500 상승 …
- 계단은 하나의 블록 단위로 단번에 Z축 500 상승
- 계단 높이 누적: 12단 × 3바퀴 = 총 36단 → Z축 총 높이: 100 + (500 * 36) = 18100

3. 블록 배치 및 구성 제한
- 모든 블록의 좌표는 (100 * 정수) 단위로 설정
- 하나의 좌표에 중복된 블록이 있어선 안 됨 (ID 충돌 주의)
- 모든 블록은 "rotation": (0,0,0) 고정

:page_facing_up: Json 구성 관련 규칙
- 각 블록은 다음 형식을 따름:
{
  "saveDataArray": [
    {
      "id": "문자열 형식의 고유 ID (예: '1014')",
      "position": {
        "x": 정수 (100의 배수),
        "y": 정수 (100의 배수),
        "z": 정수 (100의 배수)
      },
      "rotation": {
        "pitch": 정수 (보통 0),
        "yaw": 정수 (보통 0),
        "roll": 정수 (보통 0)
      },
      "size": {
        "x": 정수 (보통 1),
        "y": 정수 (보통 1),
        "z": 정수 (보통 1)
      }
    }
  ]
}


:white_check_mark: 자동화 시 주의
- 경로 곡선 계산 시 중심(4600,500) 기준 각도별 (cos, sin) 연산 필요
- 나선형 바퀴는 각도 변화와 Z 상승을 함께 적용해야 함
- 경로 간격/궤도/중복검사는 반드시 자동 검증
